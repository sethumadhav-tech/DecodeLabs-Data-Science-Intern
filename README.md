# 🛒 E-Commerce Sales Data Analysis

## 📌 Project Overview

This project is my **first Data Science project** completed as part of the **DecodeLabs Data Science Program**.

The objective of this project was to perform **Exploratory Data Analysis (EDA)** on an E-commerce Sales dataset to uncover customer purchasing behavior, identify sales trends, engineer meaningful features, and generate actionable business insights.

Through this project, I applied the complete data analytics workflow—from data cleaning and preprocessing to visualization and business insight generation.

---

## 🎯 Objectives

* Clean and preprocess the dataset
* Handle missing values and duplicate records
* Perform Exploratory Data Analysis (EDA)
* Detect outliers using statistical techniques
* Engineer new business features
* Analyze customer purchasing behavior
* Visualize sales trends
* Generate actionable business insights

# 📊 Key Insights

### 📌 Coupon Usage

* Approximately **25.75% of orders** were placed **without using coupon codes**, indicating that many customers purchased products without promotional discounts.

### 📌 Top Revenue-Generating Products

* **Chair**, **Printer**, and **Laptop** emerged as the highest revenue-generating products.

### 📌 Customer Purchasing Pattern

* Customers spent **slightly more on weekdays than weekends**, suggesting opportunities for targeted promotional campaigns during weekends.

### 📌 Business Intelligence

* Feature engineering and correlation analysis helped uncover meaningful purchasing trends that can support pricing strategies, inventory planning, and product segmentation.
